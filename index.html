Import

All four read a JSON file, but do four completely different things with it — pick the one that matches what you actually want.

Import JSON

Replaces your current board, right now.

Loads a previously exported configuration onto the board, overwriting whatever is on screen. Use this to resume work you saved earlier. (Undo can bring your prior board back if this was a mistake.)

Import Comparison Scenario

Adds a comparison target. Your board is untouched.

Adds a single named position (one target value per clause) to your custom-scenario library. Use this to bring in someone else's negotiating position — a firm's house standard, a counterparty's known ask — so it shows up in the Scenario dropdown, Compare, Schedule Redline, and Negotiation Scenarios. It is a fixed target: nothing is flagged live on your board.

Import Guardrails

Flags your board live, as you edit. Your board is untouched.

Adds a tiered rule set — a preferred value and acceptable fallbacks per clause, not just one target. Once picked from the "Guardrails" dropdown, every card on the board is tagged Preferred / Fallback / Outside Guardrails in real time, before you ever ask to be scored.

Import Favorability Ruleset

Overrides this tool's built-in polarity. Your board is untouched.

This tool's own dealer/buy-side/neutral tag on each clause option is an editorial judgment, not a fact. A favorability ruleset lets someone substitute their own judgment — once picked from the "Favorability" dropdown, it actually changes the Risk Gauge score, board tags, and outputs for every clause it covers, not just how they're displayed. Coverage can be partial: anything the file doesn't mention keeps this tool's built-in tag.

Select Clauses to Tinker With

Some basic, commonly-negotiated clauses are pre-checked to start — add anything else you want to tinker with. Unchecked clauses are hidden from the board-view and left at their default values; be aware that they still count toward the risk score and appear in outputs.

Compare Configurations

Only clauses currently visible on the board (per Vanilla mode / Select Clauses) are compared, and only rows that actually differ are shown.

Negotiation Scenarios

Pick a realistic counterparty scenario and which side you're advising. The board resets to its initial blank slate. Configure it as you'd actually negotiate, then use "Score My Negotiation" to compare against a vetted market outcome for that scenario and know where you differ.

What Breaks? — Stress Test Simulator

Trace a market/credit event through your current board configuration to see exactly which clauses fire, in order, and which stay silent because nothing was negotiated to catch this case.

Saved Scenarios

A saved scenario is one live deal — its own round history and closing checklist, separate from the scratch board. Opening a saved scenario loads its latest round onto the board.
